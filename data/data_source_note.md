# 数据来源说明

## 1. 年报文本数据

- **来源**：巨潮资讯网（www.cninfo.com.cn）披露的上市公司年度报告。
- **获取方式**：通过 Python 脚本批量下载 PDF 文件，并使用 `pdfplumber` / `PyPDF2` 转换为纯文本（TXT）。
- **本仓库使用数据**：由于真实年报数据量大、下载与解析耗时较长，本仓库在可复现代码中使用 `01_data_generation.py` 生成的模拟年报文本。模拟文本按照中国上市公司年报的行文结构与真实数据统计特征生成，用于完整演示研究流程。

## 2. 财务数据

- **来源**：CSMAR 国泰安数据库、Wind 金融终端。
- **变量**：企业规模（总资产）、资产负债率、资产收益率、研发投入强度、全要素生产率、企业年龄、行业分类等。
- **本仓库使用数据**：模拟生成，变量分布参照真实上市公司财务数据特征。

## 3. 行业分类

- **标准**：中国证监会 2012 年行业分类标准。
- **说明**：本研究剔除了金融类上市公司，并对制造业、信息技术、医药生物等行业进行了分类。

## 4. 模拟数据处理步骤

1. 设定 400 家企业，时间跨度 2015—2022 年，共 3200 条观测值。
2. 按行业设定基础数字化水平（信息技术 > 制造业 > 金融业等）。
3. 加入企业个体效应、年度时间趋势与随机扰动项。
4. 根据数字化水平生成包含数字化关键词的年报文本。
5. 根据数字化水平生成与未来研发投入、全要素生产率相关的财务变量。
6. 输出为 `data/simulated_panel.csv`。

## 5. 数据文件清单

| 文件 | 说明 |
|:----|:----|
| `data/simulated_panel.csv` | 企业-年份面板数据，含年报文本与财务变量 |
| `results/preprocessed_data.csv` | 预处理后的分词文本数据 |
| `results/dti_results.csv` | 数字化转型测度结果 |
| `results/descriptive_stats.csv` | 描述性统计结果 |
| `results/correlation_matrix.csv` | 相关性矩阵 |
| `results/reliability_validity.csv` | 信效度检验结果 |
| `results/regression_rd.csv` | 研发投入回归结果 |
| `results/regression_tfp.csv` | 全要素生产率回归结果 |
