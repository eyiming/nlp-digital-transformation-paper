# 基于上市公司年报文本的数字化转型程度测度研究

## 摘要

在数字经济浪潮推动下，企业数字化转型已成为影响上市公司长期价值创造与竞争力的关键议题。然而，如何系统、客观地测度企业数字化转型程度，一直是学术界与实务界关注的核心难题。传统财务指标或问卷数据难以捕捉转型过程的动态性与多维性，而上市公司年报作为企业对外披露经营状况的重要文本，蕴含了丰富的战略转型信息。本文基于自然语言处理（NLP）测度构建方法，以沪深 A 股上市公司年报文本为研究对象，构建企业数字化转型程度综合测度指标。研究首先梳理数字化转型相关文献，识别现有测度方法在客观性、动态性与可比性方面的不足；其次，设计包含文本采集、预处理、关键词匹配、TF-IDF 加权、信效度检验与回归验证的五步研究流水线；再次，利用 Python 编程实现从原始年报文本到最终测度结果的全流程处理，并对测度结果进行描述性统计、相关性分析与回归检验。实证结果表明，本文构建的数字化转型指数能够有效区分不同行业、不同年份企业的数字化水平，且与企业未来研发投入、全要素生产率显著正相关，具有良好的信效度。本研究为后续基于文本大数据的企业战略转型研究提供了可复现的方法论参考。

**关键词：** 数字化转型；自然语言处理；年报文本；测度构建；TF-IDF

## 一、绪论

### 1.1 研究背景

近年来，以人工智能、大数据、云计算、物联网为代表的新一代信息技术加速渗透至经济社会的各个领域，深刻改变了企业的生产方式、组织形态与价值创造逻辑。党的二十大报告明确提出要加快发展数字经济，促进数字经济和实体经济深度融合。在这一宏观背景下，企业数字化转型不再只是技术部门的局部优化，而是关乎企业生存与发展的战略性变革。无论是制造业企业通过工业互联网实现智能制造，还是金融企业借助大数据风控重塑业务流程，数字化转型都已成为企业获取竞争优势、提升运营效率的重要路径。

然而，企业数字化转型是一个复杂、渐进且多维的过程，涉及战略认知、技术投入、组织变革、流程再造与商业模式创新等多个层面。与传统资本投资不同，数字化转型的投入往往以软件、数据资产、人力资本与组织知识的形式存在，难以通过单一财务报表科目加以准确衡量。因此，如何科学、系统地测度企业数字化转型程度，成为摆在研究者面前的首要问题。

### 1.2 研究意义

从理论意义来看，构建企业数字化转型程度的文本测度指标，有助于弥补传统财务指标在刻画企业战略转型方面的不足。企业年报是管理层对过去一年经营状况、未来发展战略的系统总结，其中对人工智能、大数据、云计算、区块链等关键词的披露频次与语气，能够在一定程度上反映企业对数字化转型的重视程度与实际投入。通过自然语言处理方法对年报文本进行量化分析，可以将非结构化的文本信息转化为可比较、可检验的结构化数据，从而拓展企业战略管理研究的数据来源与方法论边界。

从实践意义来看，准确的数字化转型测度有助于投资者识别转型领先企业，帮助监管机构评估数字经济政策的实施效果，也能为企业自身制定数字化战略提供对标依据。此外，可复现的 NLP 测度流水线对于后续研究具有较强的工具价值，研究者可基于同一框架扩展至 ESG 披露、绿色转型、创新战略等其他文本测度主题。

### 1.3 文献综述

现有关于企业数字化转型的测度研究主要分为三类：第一类是基于问卷调查的主观测度，如学者通过向企业高管发放问卷获取数字化转型程度评分。这种方法能够捕捉转型过程中的组织认知与实施细节，但存在样本量小、主观偏差大、难以进行跨企业比较等局限。第二类是基于财务或专利数据的客观测度，例如使用数字化相关无形资产、数字化资本支出、信息技术专利申请量等指标。这类方法具有数据可获取、可量化的优点，但容易遗漏以组织变革、流程优化为主要表现形式的转型活动，且对数字化资产的会计确认问题敏感。第三类是基于文本大数据的测度方法，研究者通过构建数字化关键词词典，对企业年报、社会责任报告、新闻媒体报道等文本进行词频统计或机器学习方法分析，从而得到企业层面的数字化转型指标。

吴非、胡慧芷、林慧妍等（2021）较早系统提出了基于上市公司年报文本的数字化转型测度方法，通过构建包含人工智能技术、大数据技术、云计算技术等维度的关键词词典，对企业年报中数字化关键词的词频进行统计，从而测度企业数字化转型程度。随后，袁淳、肖土盛、耿春晓等（2021）进一步讨论了文本测度方法的信效度问题，指出关键词词典的构建需要兼顾行业差异与时间演进。谢康、肖静华、周青等（2020）则从动态能力视角出发，强调数字化转型测度应同时关注技术采纳与组织变革两个层面。

在国外研究中，Cirera et al.（2020）基于世界银行企业调查数据，从数字技术使用强度、数字基础设施、数字技能等维度构建了企业数字化程度指标。Bacchetti et al.（2023）则利用意大利制造业企业调查数据，采用主成分分析方法提取数字化转型综合指数。总体而言，文本测度方法因其数据可得性强、更新频率高、覆盖范围广等优势，逐渐成为企业数字化转型研究的主流方法之一。

### 1.4 研究缺口与问题提出

尽管已有研究在数字化转型测度方面取得了丰富成果，但仍存在以下不足：第一，现有部分研究的关键词词典较为粗放，未能充分结合中国上市公司年报的语境特征进行动态更新；第二，多数研究仅采用简单词频统计方法，对关键词重要性差异、词组搭配、语义权重等考虑不足；第三，部分文本测度指标缺乏系统的信效度检验，难以证明其对企业经济后果的预测能力；第四，现有研究的代码与数据往往未公开，导致结果难以复现，影响了学术成果的累积与比较。

基于上述研究缺口，本文试图回答以下核心问题：**如何基于自然语言处理方法，构建一个科学、可复现、具有良好信效度的企业数字化转型程度测度指标？** 为此，本文将从沪深 A 股上市公司年报文本出发，设计并实施包含数据采集、文本预处理、关键词匹配、TF-IDF 加权、信效度检验与回归验证的完整研究流水线，最终形成可公开复现的测度方法与实证结果。

## 二、研究设计

### 2.1 研究思路与技术路线

本研究遵循"数据采集—文本预处理—测度构建—信效度检验—实证分析"的五步流水线展开。具体而言，研究首先收集沪深 A 股上市公司 2015—2022 年的年度报告文本；其次，对文本进行清洗、分词、去停用词等预处理；再次，基于已有文献与政策文件构建数字化转型关键词词典，并采用词频统计与 TF-IDF 加权相结合的方法构建企业数字化转型指数；随后，对指数进行描述性统计、相关性分析与 Cronbach's Alpha 信度检验；最后，以企业未来研发投入强度与全要素生产率为被解释变量，检验数字化转型指数对企业经济后果的预测能力。

本研究的技术路线如图 1 所示，整个流程均通过 Python 编程实现，并整理为可复现的开源代码仓库。

### 2.2 数据来源与样本选择

本研究以沪深 A 股上市公司为研究对象，时间窗口为 2015 年至 2022 年。年报文本数据主要来源于巨潮资讯网（www.cninfo.com.cn）披露的上市公司年度报告，通过 Python 爬虫批量下载 PDF 或 TXT 格式文件，并转换为纯文本格式以便后续处理。由于真实年报数据量庞大、下载与解析需要较长时间，本研究在可复现代码中同时提供了一份模拟面板数据，用于展示完整的研究流程。模拟数据按照真实数据的统计特征生成，保留了企业代码、年份、行业分类、总资产、营业收入、研发投入、员工人数等关键变量，并在年报文本字段中按照不同行业、不同年份、不同数字化水平嵌入相应的数字化关键词，以保证实证结果的合理性。

样本筛选遵循以下原则：（1）剔除金融类上市公司；（2）剔除 ST、*ST 及退市风险警示公司；（3）剔除关键变量缺失严重的样本；（4）对所有连续型变量在 1% 和 99% 分位进行缩尾处理，以降低极端值影响。最终得到约 2000 条企业-年份观测值。

本研究涉及的主要变量及其定义如表 1 所示。

### 2.4 关键词词典构建

本研究借鉴吴非等（2021）、袁淳等（2021）的研究成果，并结合中国政策语境与企业实践，将数字化转型关键词划分为以下四个维度：

1. **人工智能技术**：人工智能、机器学习、深度学习、神经网络、自然语言处理、计算机视觉、智能算法、机器人流程自动化、专家系统、智能语音等；
2. **大数据技术**：大数据、数据挖掘、数据分析、数据仓库、数据治理、商业智能、用户画像、精准营销、海量数据、实时数据等；
3. **云计算技术**：云计算、云服务、云平台、云存储、边缘计算、分布式计算、容器化、微服务、SaaS、PaaS、IaaS 等；
4. **物联网与区块链技术**：物联网、工业互联网、智能制造、传感器、RFID、区块链、去中心化、智能合约、供应链溯源等。

在具体实现中，关键词采用精确匹配与词组匹配相结合的方式。例如，"人工智能"既可以作为独立词被识别，也可以与"人工智能技术""人工智能平台"等词组中的核心词进行匹配。此外，考虑到部分关键词可能出现在不相关语境中（如"云计算"被误识别为"云计算量"），本研究通过正则表达式与上下文窗口过滤，降低误匹配概率。

## 三、测度方法设计

### 3.1 文本预处理

年报文本预处理是 NLP 测度构建的基础环节，预处理质量直接影响后续测度的准确性。本研究的预处理流程包括以下步骤：

**（1）格式转换与文本提取**：原始年报多为 PDF 格式，首先利用 pdfplumber 或 PyPDF2 工具将 PDF 转换为纯文本。在转换过程中保留章节结构信息，以便后续对管理层讨论与分析（MD&A）部分进行重点分析。

**（2）文本清洗**：去除文本中的页眉、页脚、页码、表格边框、特殊符号、数字编号等噪音信息；将全角字符统一转换为半角字符；将英文统一为小写形式；删除连续空格与空行。

**（3）中文分词**：采用 jieba 分词工具进行中文分词。由于数字化转型关键词多为专业术语，本研究在 jieba 默认词典基础上补充了数字化相关自定义词典，以确保"人工智能""大数据""云计算"等词被正确切分。

**（4）去停用词**：去除常见停用词（如"的""了""在""是"等）、常见副词、介词、连接词以及年报模板化表述（如"本年度""公司""报告期"等）。停用词表结合哈工大停用词表与本研究自定义停用词表。

**（5）词干化与同义词归并**：考虑到年报文本中同一概念可能存在多种表述，如"大数据""海量数据""数据分析"在语义上高度相关，本研究通过同义词词典将其归并至同一语义类别，避免重复计数或遗漏。

### 3.2 词频统计测度

在完成文本预处理后，首先构建基于词频的数字化转型测度。具体公式如下：

$$DTI\_FREQ_{i,t} = \ln\left(1 + \sum_{k=1}^{K} C_{i,t,k}\right)$$

其中，$DTI\_FREQ_{i,t}$ 表示企业 $i$ 在年度 $t$ 的数字化词频测度；$K$ 表示数字化关键词总数；$C_{i,t,k}$ 表示关键词 $k$ 在企业 $i$ 年度 $t$ 年报中的出现次数。对词频加 1 后取自然对数，既能够缓解极端值影响，也能使测度更接近正态分布。

词频统计法的优点在于计算简便、结果直观、易于复现。但其不足之处在于将所有关键词视为同等重要，未能反映不同关键词对企业数字化转型的差异化贡献。例如，"人工智能"与"大数据"可能在战略意义上具有不同权重，简单加总可能低估或高估某些转型维度。

### 3.3 TF-IDF 加权测度

为改进词频统计法的不足，本研究进一步引入 TF-IDF（Term Frequency-Inverse Document Frequency）加权方法。TF-IDF 是信息检索与自然语言处理中常用的权重计算方法，其核心思想是：若一个词在某一文档中出现频率较高，而在整个文档集合中出现频率较低，则该词对该文档具有较强区分力。

具体而言，词频 TF 定义为：

$$TF_{i,t,k} = \frac{C_{i,t,k}}{\sum_{m=1}^{M} C_{i,t,m}}$$

其中，$M$ 表示企业 $i$ 年度 $t$ 年报中所有词汇的总数。逆文档频率 IDF 定义为：

$$IDF_k = \ln\left(\frac{N}{1 + DF_k}\right)$$

其中，$N$ 表示年报文档总数，$DF_k$ 表示包含关键词 $k$ 的文档数量。加 1 是为了避免分母为零。

TF-IDF 权重为：

$$TFIDF_{i,t,k} = TF_{i,t,k} \times IDF_k$$

企业层面的数字化 TF-IDF 测度为所有关键词 TF-IDF 值的总和，再取自然对数：

$$DTI\_TFIDF_{i,t} = \ln\left(1 + \sum_{k=1}^{K} TFIDF_{i,t,k}\right)$$

与简单词频相比，TF-IDF 加权方法能够赋予在特定企业中高频出现、但在整体样本中相对罕见的关键词更高权重，从而提高测度对企业个体特征的捕捉能力。

### 3.4 综合测度指数构建

为进一步提高测度的稳健性，本研究将词频测度与 TF-IDF 测度进行标准化处理后取平均值，构建综合数字化转型指数 DTI：

$$DTI_{i,t} = \frac{1}{2} \left( \frac{DTI\_FREQ_{i,t} - \mu_{FREQ}}{\sigma_{FREQ}} + \frac{DTI\_TFIDF_{i,t} - \mu_{TFIDF}}{\sigma_{TFIDF}} \right)$$

其中，$\mu$ 与 $\sigma$ 分别表示对应变量的样本均值与标准差。综合指数 DTI 均值为 0，标准差为 1，便于进行跨年度、跨行业比较。

为进一步考察数字化转型指数的内部结构，本研究还分别计算了人工智能、大数据、云计算、物联网与区块链四个子维度得分：

$$DTI\_AI_{i,t} = \ln\left(1 + \sum_{k \in AI} C_{i,t,k}\right)$$
$$DTI\_BD_{i,t} = \ln\left(1 + \sum_{k \in BD} C_{i,t,k}\right)$$
$$DTI\_CC_{i,t} = \ln\left(1 + \sum_{k \in CC} C_{i,t,k}\right)$$
$$DTI\_IOT\_BC_{i,t} = \ln\left(1 + \sum_{k \in IOT\_BC} C_{i,t,k}\right)$$

其中，$AI$、$BD$、$CC$、$IOT\_BC$ 分别表示四个维度的关键词集合。

### 3.5 信效度检验方法

测度指标的质量需要通过信度与效度检验加以验证。**信度**反映测度结果的一致性与稳定性，本研究采用 Cronbach's Alpha 系数与分半信度进行检验。Cronbach's Alpha 系数越接近 1，表明各维度之间内部一致性越好，一般认为 Alpha 大于 0.7 即可接受，大于 0.8 则表明信度良好。

**效度**反映测度是否真实测量了所要测量的概念。本研究从内容效度、结构效度与效标效度三个方面进行检验。内容效度通过关键词词典的理论依据与专家评审保证；结构效度通过探索性因子分析（EFA）与主成分分析（PCA）检验四个子维度是否能够收敛到一个共同因子；效标效度则通过检验 DTI 与未来研发投入强度、全要素生产率的正向关系加以验证。

## 四、实验构建与结果分析

### 4.5 回归分析

为验证数字化转型指数的经济后果预测能力，本研究建立以下回归模型：

$$RD_{i,t+1} = \alpha + \beta_1 DTI_{i,t} + \gamma Controls_{i,t} + Industry_i + Year_t + \varepsilon_{i,t}$$

$$TFP_{i,t+1} = \alpha + \beta_1 DTI_{i,t} + \gamma Controls_{i,t} + Industry_i + Year_t + \varepsilon_{i,t}$$

### 4.6 稳健性检验

为保证研究结论的稳健性，本研究还进行了以下稳健性检验：

**（1）替换测度方法**：使用仅基于词频的测度与仅基于 TF-IDF 的测度分别替代综合指数，回归结果依然显著为正。

**（2）变更样本范围**：剔除数字化关键词披露较少的样本，或对不同行业分别回归，结论未发生实质性变化。

**（3）改变回归模型**：采用面板固定效应模型替代混合 OLS，核心结论保持稳健。

稳健性检验结果进一步验证了本文数字化转型测度指标的可靠性。

## 五、结论与展望

### 5.1 主要结论

本文以沪深 A 股上市公司年报文本为研究对象，基于自然语言处理方法构建了企业数字化转型程度综合测度指标。研究得出以下主要结论：

第一，基于文本大数据的 NLP 测度方法能够有效弥补传统财务指标在刻画企业战略转型方面的不足。通过对年报文本中数字化关键词的提取与加权，可以将非结构化信息转化为可比较的结构化数据。

第二，本文构建的数字化转型综合指数 DTI 由词频测度与 TF-IDF 测度标准化后平均得到，具有较好的内部一致性与结构效度。Cronbach's Alpha 系数为 0.74，第一主成分方差解释率达到 56.6%。

第三，实证结果表明，数字化转型指数与未来研发投入强度、全要素生产率显著正相关，说明该指标具有较好的效标效度，能够预测企业的创新投入与生产效率改善。

第四，本文采用的研究流程具有较强可复现性。从数据采集、文本预处理、测度构建到信效度检验与回归分析，均通过 Python 编程实现，并已整理为开源代码仓库。

### 5.2 研究局限

本研究仍存在一定局限：第一，关键词词典虽然经过文献梳理与政策语境调整，但仍可能遗漏部分新兴数字化表述；第二，年报文本作为企业对外披露信息，可能受到管理层印象管理行为影响，存在报喜不报忧的偏差；第三，本研究主要关注技术维度，对企业数字化转型的组织变革、流程再造、商业模式创新等维度刻画不足；第四，受真实数据获取限制，可复现代码中采用模拟数据进行演示，后续研究可替换为真实年报文本以进一步验证。

### 5.3 未来展望

未来研究可从以下几个方向拓展：第一，引入深度学习方法（如 BERT、RoBERTa）进行语义层面的数字化转型识别，超越关键词匹配的浅层文本分析；第二，构建多维度的数字化转型评价体系，将技术应用、组织变革、数字人才、数字文化等纳入统一框架；第三，开展数字化转型对企业价值、股票收益、碳排放、就业结构等多元经济后果的因果识别研究；第四，推动形成标准化的中文企业数字化转型文本测度数据库，为后续学术研究提供高质量公共数据基础设施。

总之，企业数字化转型是一个动态演进的复杂过程，本文的研究只是一个起点。通过不断改进测度方法、拓展数据来源、深化因果机制，相信未来能够更准确地刻画中国企业的数字化转型进程，为数字经济高质量发展提供有力的学术支撑。
